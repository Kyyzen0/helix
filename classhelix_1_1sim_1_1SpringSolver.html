Detailed Description

A hanging lattice of points joined by springs.

The solver is stepped by hand, so the same steps in the same order always give the same answer. Nothing in it reads a clock or a random source.

Example

helix::sim::SpringSolver solver;
solver.reset(settings);
solver.step(settings, 1.f / 24.f);
