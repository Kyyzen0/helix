Detailed Description

What a face is made of, as the file described it. Immutable once built, shared by std::shared_ptr<const Material> between every mesh that uses it.

A mesh holds a table of materials and a material_index face attribute that points into it (see Mesh::materials). Only the base colour is kept: no other map is read yet.
