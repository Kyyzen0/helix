Detailed Description

Reads the settings of a simulation at a frame, keyframes included.

The helpers here are what a node calls to gather its settings. Every value is read through the keyframe store, so a setting that holds keyframes gives the value its track holds at that frame, and any other setting gives the value it holds now.

Note
A header rather than a source file, so a node can use it without the engine library having to know about it.
