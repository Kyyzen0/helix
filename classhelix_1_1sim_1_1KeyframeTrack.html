Detailed Description

The keyframes of one component of one parameter, and the value it falls back on when it holds none.

A track is a pure function of the frame it is given. The same track and the same frame always give the same value, whatever order the frames were asked for in, so scrubbing back and forth gives the same answer as playing forwards.

Example

helix::sim::KeyframeTrack track;
track.addKeyframe(1.f, 0.f, helix::sim::Interpolation::Linear);
track.addKeyframe(11.f, 10.f, helix::sim::Interpolation::Linear);
track.evaluate(6.f); // 5
