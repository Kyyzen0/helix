Detailed Description

Reads the skin and the animations of an Assimp scene.

Assimp gives every mesh its own list of bones, each naming a node of the hierarchy, so the joints are collected once for the whole file, by node, and every mesh weights the same joint list. The joints are put in depth first order, so a parent always comes before its children.

Two meshes may skin to the same node with different inverse bind matrices. The node then has one joint per matrix, all with the same name, parent and rest pose, and each mesh weights the one that carries its matrix; a clip moves all of them alike. The nodes above the bones that a clip animates are joints too, with no weight, so the clip can move the rig through them.
