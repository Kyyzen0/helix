Detailed Description

Holds the keyframes of every animated value in the scene.

The store is the one place a keyframe lives. It knows which parameter each track belongs to, and it keeps the value the parameter held before the track was made, so removing the track puts the parameter back as it was.

The store listens to the scene moving to a new frame. When it does, every track is resolved at that frame and the result is written into the parameter it belongs to, which dirties the node and makes the engine cook it again. A keyframed parameter therefore reads its animated value the same way any other parameter reads its value, with no special case in the cook.

Note
A singleton, since the tracks belong to the scene rather than to any one part of it.

Example

auto& store = enzo::sim::KeyframeStore::instance();
store.setKeyframe({nodeId, "translate", 1}, 1.f, 0.f);
store.setKeyframe({nodeId, "translate", 1}, 24.f, 10.f);
store.evaluate({nodeId, "translate", 1}, 12.5f); // 4.807692
