Detailed Description

Base class for all primitive types in the engine.

A Primitive is the unit of geometry exchanged between nodes. It holds primitive-level attributes (one value per object) and provides the attribute management API shared by all primitive types.

Point attributes are stored on the base class since many primitive types have points. Use hasPoints() to check before accessing them.

Subclasses (e.g. Mesh) add their own attribute owners and geometry.

◆ ensureWritable()

virtual void helix::geo::Primitive::ensureWritable ( )
inlinevirtual

Gives the intrinsic attributes a store of their own and rebinds the primitive's handles to it, when a copy still shares them.

Copies share their attribute stores with the original until written (copy on write). Subclasses that keep handles on intrinsic attributes override this and call it before each write. Called by tryAddAttribute before it returns a shared intrinsic attribute.

Reimplemented in helix::geo::Camera, and helix::geo::Mesh.
