Detailed Description

The nodes one cook covers and the order they are cooked in.

A plan is built once, on the thread that owns the network, before any worker touches it. Workers then read the plan and never the graph, so the graph is only ever read while no cook is running.

The plan holds the nodes grouped into levels. Every node in a level reads only nodes in earlier levels, so a whole level can be cooked at the same time as the next one cannot start until the level before it has finished.

Note
Nodes in one level are sorted by id, so the same network always gives the same plan and a cook gives the same result however the work is spread over threads.
