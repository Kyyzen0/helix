Detailed Description

What a skeleton carries besides its points, shared by every copy of the mesh.

A skeleton is a mesh whose points are the joints, so the transforms (rest_local, inverse_bind, pose) live in point attributes where every node can read them. What does not fit a point attribute lives here: the names, the clips, and the transform above each root joint.

Immutable, shared by pointer like the materials of a mesh, and not saved in a scene: the import node reads it again from the file.
