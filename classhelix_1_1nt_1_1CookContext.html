Detailed Description

The handle a node holds while it cooks to get context about the network.

Carries the runtime context a cook reads from the network, covering parameter values, input geometry and the scene time.

Note
A context comes in two kinds. The ordinary one reads the live network, and it is the one the single threaded cook uses. The other reads a snapshot taken before the cook started, and it is the one a cook on a worker thread uses. The snapshot kind never reads the network, so a cook using it touches no shared engine state and several of them can run at once.
