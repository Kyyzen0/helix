std::size_t helix::NodePacket::estimateBytes ( ) const

Estimates how much memory the packet holds, in bytes.

Adds up every attribute and group of every primitive, the intrinsic ones included. A store that two attributes share (copy on write, see attr::Attribute) is counted once for each of them, so the estimate errs on the high side. A texture of a material is not counted, since every copy of a mesh shares it.

std::uint64_t helix::NodePacket::identity ( ) const
inline

Returns a number that tells this packet from every other one a node published.

A node stamps the packet it hands to an output (nt::Node::setOutputPacket), drawing from one counter shared by every node, so two different results never carry the same number. A packet nothing stamped, such as the empty one an output holds before a cook, reads zero. The cook cache files a node's output under the numbers of the packets that came in, so the output is only reused when its inputs are the very packets it was made from.

Note
A copy keeps the number of the packet it was copied from, until it is stamped itself.
