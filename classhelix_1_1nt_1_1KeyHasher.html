Detailed Description

Builds a 64 bit key out of the values a cook reads.

The cook cache (see nt::CookCache) files a node's output under a key that stands for everything the cook depends on. Two cooks that read the same values in the same order get the same key, and a change to any value, or to the order they were added in, changes it.

Example

nt::KeyHasher hasher;
hasher.add(nodeTypeName);
hasher.add(frame);
const std::uint64_t key = hasher.value();
