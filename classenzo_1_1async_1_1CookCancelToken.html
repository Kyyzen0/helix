Detailed Description

A shared flag a cook polls to learn whether it should stop.

The token is shared with the cook, so whoever asks for a new cook can raise the flag without waiting for the running one to notice, and the running one stops at the next point where it checks.

Note
The flag only says "stop soon". A node that is already cooking runs to its end, because a node cook cannot be unwound part way through.
