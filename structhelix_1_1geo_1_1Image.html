Detailed Description

A picture a material uses, decoded to pixels.

Immutable once built: it is shared through std::shared_ptr<const Image> by every material that uses it, and by every copy of a mesh.

Conventions
  • 8 bits per channel, four channels (red, green, blue, alpha), width * height * 4 bytes.
  • sRGB encoded, alpha not premultiplied. A shader that samples it through an sRGB texture format gets linear values.
  • Rows run from the top of the picture to the bottom.
  • The uv attribute of a mesh has its origin at the bottom left, v pointing up, which is what Assimp (every format it reads, glTF included, whose own origin is the top left), Model I/O and the obj reader all give. The texel for (u, v) is therefore at column u * width and row (1 - v) * height counted from the top. sampleNearest does exactly that.
