Detailed Description

Everything one cook reads from the network, taken before the cook starts.

A cook reads parameters, the frame, and the wiring of the network. All three can change while a cook runs, so they are read once on the thread that owns the network and handed to the cook as a fixed picture.

Reading a fixed picture is what lets a cook run on several threads without fighting the interface: the workers never read the live network, so the interface is free to change it while they work.

Note
A snapshot is taken per cook. A new cook takes a new one, so an edit made during a cook shows up in the cook that follows it.
